# AI Citation Link Prospector

1. `pip install -r requirements.txt`
2. Set keys (or paste them in the sidebar):
   - GEMINI_API_KEY   – free at aistudio.google.com
   - PERPLEXITY_API_KEY – perplexity.ai/settings/api (needs a few $ credit)
   - OPENAI_API_KEY   – platform.openai.com
   - ANTHROPIC_API_KEY – optional, console.anthropic.com
3. `streamlit run app.py`
4. Every run is saved to runs/*.json — use "Load a saved run" in the sidebar as a demo backup.
